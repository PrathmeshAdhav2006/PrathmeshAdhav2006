### 🌟 Featured Project

#### 🔹 [P1-Boardgame: End-to-End DevOps CI/CD Pipeline](#)
*A production-style CI/CD pipeline for a Java Spring Boot application, deployed and monitored on Kubernetes.*

- 🏗️ Built a fully declarative **Jenkins CI/CD pipeline** integrating Git, Maven builds, **SonarQube** quality gates, and **Trivy** vulnerability scanning
- 📦 Automated artifact management with **Nexus Repository** and containerized the app with **Docker**, pushing security-scanned images to Docker Hub
- ☸️ Deployed to a self-managed **Kubernetes cluster** (kubeadm on AWS EC2) using namespace-scoped **RBAC** for least-privilege CI/CD access
- 📊 Implemented full-stack observability with **Prometheus, Node Exporter, and Blackbox Exporter**, visualized via **Grafana** dashboards
- 📧 Automated Jenkins email notifications with build status and Trivy reports
